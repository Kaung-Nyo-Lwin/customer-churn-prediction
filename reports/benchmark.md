# Reproduced benchmark

Generated by `python model_train.py`. Values below come from the same run as the adjacent JSON report and model artifact.

**Data:** 7,043 accounts, 19 features, 26.5% observed churn.

**Split:** 5,634 training / 1,409 holdout accounts; 374 holdout churners; stratified by churn, seed 42.

**Threshold policy:** Maximize F2 over 0.10–0.80 on five-fold OOF training scores. The holdout is excluded from fitting and threshold selection.

## Demo model

Value-aware gradient boosting is retained to explore the original four-class research question. This designation is set before viewing holdout results.

| Actual / predicted | No review | Review |
| --- | ---: | ---: |
| No churn | 595 | 440 |
| Churn | 41 | 333 |

The review queue contains 333 churners and 440 false alerts. Four-class argmax accuracy is 80.1%; it uses a different decision rule from the binary review threshold above.

The observed-value cutoff is **$1,398.125** in historical charges, learned from the training partition. Missing historical charges are assigned to the lower observed-value tier; numeric model inputs use training-median imputation.

## Historical-charge diagnostic

Missed churners account for **$108,706.55** in recorded historical charges (20.8% of the holdout churners' recorded charges). This is an exposure proxy. It does not estimate future revenue loss, retention uplift, or revenue saved.
